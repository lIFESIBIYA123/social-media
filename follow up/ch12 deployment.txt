python manage.py check –deploy

That’s a lot of things. As we are building an API, let’s focus on the security issues that concern our API:

    • SECRET_KEY: This is an important setting in Django. It is used for all sessions, cryptographic 
        signings, and even PasswordReset tokens. Having an already set value for SECRET_KEY
        can lead to dangerous security issues such as privilege escalation and remote code execution.

    • DEBUG, which is set to True. That is basically why we were able to see the DisallowedHost
        error. Imagine an attacker going through your API, causing a 500 error, and then being able 
        to read everything. That would be very bad.
